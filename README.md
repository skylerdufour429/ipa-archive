# IPA Archive - App to Home Screen

A GitHub Pages + GitHub Codespaces-ready web app for browsing iOS IPA archives.

## Features

- App list
- Bundle ID display
- Version information
- Platform details
- Minimum iOS version
- File size
- IPA download buttons
- Add website to Home Screen support
- Progressive Web App (PWA) support

## GitHub Pages

Enable:

Settings → Pages → Deploy from branch

Branch:

main

Folder:

/root

## Install on Home Screen

On iPhone/iPad:

1. Open the GitHub Pages website in Safari.
2. Tap Share.
3. Select "Add to Home Screen".
4. Tap Add.

The website will launch like an app.
